# DEAS México - Website

Este proyecto es la página web para **DEAS México**, una empresa enfocada en la construcción de experiencias publicitarias de marca, stands, displays y BTL.

## 📝 Descripción del Proyecto

El sitio web está diseñado de forma estática y funcional para presentar los servicios de la empresa, su portafolio de proyectos destacados, e información sobre las marcas con las que han colaborado. Ofrece también un medio de contacto fluido y directo para clientes potenciales.

La página cuenta con secciones clave como:
- **¿Quiénes Somos?**: Información sobre la visión, valores y experiencia del equipo.
- **Proyectos**: Vista de los trabajos más destacados desarrollados por la agencia.
- **Servicios**: Detalle de la oferta de valor (Stands, Displays, BTL).
- **Contacto**: Formulario en PHP para enviar mensajes directos, así como enlaces a WhatsApp, correo corporativo y redes sociales.

## ✨ Características

- **Diseño Responsivo**: El proyecto está desarrollado para ser completamente adaptable a diferentes tamaños de pantalla, asegurando una experiencia de usuario óptima y fluida tanto en dispositivos móviles y tablets como en computadoras de escritorio.
- **Tecnologías**: Construido utilizando HTML5, CSS3, JavaScript (para interactividad de menús y galerías) y PHP (para el envío de correos).

## 🚀 Despliegue

Este proyecto se encuentra actualmente desplegado y alojado a través de **Hostinger**.
